## Development workflow

1. Create a branch from `main`.
2. Implement changes with unit tests in `src/__tests__`.
3. Ensure `npm test` and `npm run typecheck` pass locally.
4. Open a pull request — CI runs automatically.
5. Request review from at least one other contributor.

## Testing

Run the full suite:

```bash
npm test
```

Add new tests in `src/__tests__` alongside the module they cover.
